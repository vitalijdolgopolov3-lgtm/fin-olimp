# ФинОлимп — версия 8

Полная версия для замены исходных файлов в GitHub. На главной добавлены данные команды: 26 дипломов в прошлом сезоне (14 победителей, 12 призёров), цель 50+ и бесплатная индивидуальная консультация у @fin_olimps_manager.

Не удаляйте Railway Volume `/app/data` и переменную окружения `ADMIN_PASSWORD`. Этот архив не содержит папку `data` и не должен перезаписывать существующую видеотеку. При загрузке через GitHub Desktop сохраните структуру каталогов, замените содержимое репозитория, выполните commit и push. Проверяйте новое развёртывание в Railway.

Статьи на отдельных страницах — редакционные материалы, а не дословные Telegram-посты.
