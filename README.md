# Фин Олимп — обновлённая версия сайта

## Обновление текущего Railway
1. Распакуйте архив и загрузите **содержимое** папки в существующий GitHub-репозиторий `fin-olimp`, заменив одноимённые файлы. Не удаляйте репозиторий и не создавайте новый Railway-проект.
2. Railway развернёт изменения автоматически. Переменная `ADMIN_PASSWORD` сохранится.
3. Убедитесь, что Volume по-прежнему подключён в Railway по пути `/app/data`. Это позволяет сохранить добавленные ранее видео.
4. Проверьте главную страницу, `/otzyvy/`, `/sitemap.xml`, добавление видео в админ-панели.

## SEO
Главная страница включает поисковые формулировки олимпиад, заголовки, meta-description; динамическая карта сайта `/sitemap.xml`. После получения домена добавьте сайт в Яндекс Вебмастер и Google Search Console. Индексация и позиции не гарантируются.

## Отзывы
10 подлинных отзывов переписаны с присланных пользователем скриншотов Telegram-подарков. Оригиналы сохранены в `public/assets/reviews`.

## Запуск локально
Установите Node.js 18+, задайте `ADMIN_PASSWORD` (минимум 12 символов), выполните `node server.js`; сайт откроется на `http://localhost:3000`.
