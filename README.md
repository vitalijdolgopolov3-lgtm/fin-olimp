# Фин Олимп — сайт школы

Готовый адаптивный сайт с видеокаталогом и простой админ-панелью. Основан на открытом описании Telegram-канала https://t.me/fin_olimps и публичной перепубликации сообщения школы. Это первая версия, не официальный сайт до согласования со школой.

## Требования
Node.js 18+ (лучше 20/22). Никаких сторонних npm-зависимостей.

## Запуск

**Windows (PowerShell):**

```powershell
$env:ADMIN_PASSWORD="Придумайте_длинный_уникальный_пароль_123!"
node server.js
```

**macOS / Linux:**

```bash
ADMIN_PASSWORD='Придумайте_длинный_уникальный_пароль_123!' node server.js
```

Откройте http://localhost:3000 . Внизу сайта нажмите «Администратор», войдите с вашим паролем и добавляйте ссылки на видео. Для учеников видео будут видны без пароля.

## Что поддерживается

- Добавление ссылки на любое публично доступное видео (YouTube, VK Видео, Rutube, Telegram и прочее) с названием, категорией и описанием.
- Удобный поиск и фильтрация по категориям.
- Удаление видеозаписей через панель администратора.
- Постоянное хранение видео в `data/videos.json` на сервере, а не только в браузере.
- Ссылки открываются в новой вкладке. Прямого воспроизведения внутри сайта пока нет: оно зависит от сервиса видео.

## Публикация в интернете

Разместите весь проект на Node.js-хостинге, где файловая система постоянная (либо подключён постоянный диск/volume). Установите переменную окружения `ADMIN_PASSWORD` (сложный уникальный пароль от 12 символов), команду запуска `node server.js`, и включите HTTPS на домене. **Важно:** на хостингах с временной файловой системой видео из `data/videos.json` могут пропасть после перезапуска или обновления, поэтому нужен постоянный диск или замена хранения на базу данных. Делайте резервные копии файла с видео. Не выкладывайте пароль в публичный репозиторий.

Панель администратора в этой версии рассчитана на одного администратора. Авторизация осуществляется с помощью пароля в запросах к API; публикуйте сайт только через HTTPS. Для публичного запуска при большой аудитории рекомендуется добавить ограничение числа попыток входа и надёжную сессию/авторизацию.
